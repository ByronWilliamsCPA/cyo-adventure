## Reproducing

A re-run spends real provider money and will not reproduce these numbers exactly (the
fill is non-deterministic). What should reproduce is the shape: near-zero raw survival,
`verify_manifest` at 100%, and HERO coverage at or near 100% for a contract whose fill
directives name `{HERO}` in every one of its 23 placements. A `verify_manifest` rate
below 100% on any future run is a transform-correctness regression and blocks G1-R;
a lower HERO coverage is a fill-quality signal that trips the soft floor, not a gate.

Note for anyone re-running from a worktree: `OLLAMA_CA_BUNDLE` and sibling file-path
settings resolve against the process's current working directory, which cost this run two
round trips (`AL-073`, a recurrence of `AL-056`, tracked by `UW-C22`).
