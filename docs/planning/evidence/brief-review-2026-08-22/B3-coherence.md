1. [CRITICAL] [4.1, F4] "Best judged prose" inverts the only panel evidence on record.
The brief: "DeepSeek V4 Pro emerged as the best judged prose at roughly a fifth the cost" (line 184); F4 builds on it. The only blind cross-lab panel (08-10 brief section 29, table at line 2591) puts V4 Pro at peers-only quality -0.13, FIFTH of eight, behind sonnet-5 (+0.69), grok-4.6 (+0.61), gpt-5.6-sol (+0.38), sonnet-4.6 (+0.14); section 31 states the trade: V4 Pro is "4.9x cheaper and gives up 0.74 of judged quality," while xai-grok-4.6 is "close to dominant" (best diversity 0.81, best in-band 0.99, second-best quality, ZDR endpoint, which the vendor README calls "the better default for a children's product"). No later panel exists anywhere; the claim's only other occurrence is the test plan's preamble repeating it. What V4 Pro actually won is cost per DELIVERED book ($0.0398 vs $0.186-$1.42, README "What it actually cost"). The brief converts a priced quality-for-cost trade into a false quality dominance and erases grok from the document entirely.
Recommendation: restate 4.1 as "cheapest per delivered book by 4.7x, giving up 0.74 z of judged quality vs the best measured legs," carry section 31's three-axis table forward, flag the change from the 08-10 reading as a change.
